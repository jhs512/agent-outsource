# 공개 설치 흐름 검증

2026-09-23, Windows / Node.js 24.13.1 기준.

- README를 설치 → 셋업 → 첫 작업 순서로 정리하고 이전 README와 실험 기록을 보존했다.
- 작업 스킬과 셋업 스킬을 나란히 설치한다. 런타임 npm 의존성은 없다.
- `npm test`: 19개 통과. 실제 모델 호출 없이 실행·질문·재개·복구·알림과 셋업을 검사한다.
- 셋업 테스트는 기존 DB 보존, 누락된 전제 조건, 한글·공백 경로로의 이동, 사용자별 실행파일 탐색을 확인한다.
- 로컬 설치본의 실제 셋업: Node, SQLite WAL/무결성, Codex queue, 두 CLI의 필수 옵션, Claude 로그인 확인. Antigravity 로그인은 수동 확인으로 표시한다.
- 두 스킬의 형식 검사 통과. 설치본과 소스 파일 내용이 일치하며, 교체 전후 기존 작업·실행·질문·알림·명령 레코드가 동일하다.

테스트에서 Node 24.13.1의 Windows `fs.cpSync`가 한글 대상 경로 복사 중 네이티브 종료하는 현상을 분리 재현했다. 테스트 준비에 개별 파일 복사를 사용하자 동일한 한글 경로의 모듈 로딩과 셋업 검사는 통과했다. 스킬 실행 경로는 `cpSync`를 사용하지 않는다.

셋업은 모델 호출이나 실제 알림을 보내지 않는다. 실제 작업자·알림 검증은 [앞선 실행 기록](../local-skill-verification.md)을 참고한다. 음성 통화 중 자동 발화는 검증하지 않았다.
