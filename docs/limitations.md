# 지원 범위

- Windows에서 두 실제 CLI의 결과 수신·세션 재개·질문 후 재개·취소를 검증했다. Linux 프로세스 식별 코드는 있지만 실제 CLI 통합은 미검증이다. macOS 프로세스 복구는 아직 구현하지 않았으므로 셋업에서 준비되지 않은 환경으로 표시한다.
- Claude의 일반 질문 도구는 실행 중 답을 받아 이어갈 수 있다. Antigravity는 종료 후 같은 conversation을 재개해 답을 전달한다. agy의 실시간 control-response 입력은 미지원이다.
- 두 CLI는 모든 실행에서 권한 확인을 생략한다. 이 옵션이 인증 실패나 기존 사용자 훅의 오류까지 해결하지는 않는다.
- 완료 이벤트가 원래 Codex 대화에 도착해 대화를 재개하는 것을 확인했다. 앱이 완전히 꺼져 있을 때의 최종 전달과 음성 통화 중 자동 발화는 미검증이다.
- 알림이 재전송되면 같은 이벤트를 중복 수신할 수 있다. 스킬은 이벤트 ID와 수신 확인으로 이를 구분한다. 작업 결과는 알림 실패와 별도로 보존한다.
- 프로그램 종료 중 실행 상태가 불확실해진 작업은 자동으로 반복하지 않는다. 기존 변경을 확인한 뒤 이어서 요청한다.
